## ☕ Description

This activity involved designing a promotional poster for a free coffee booth at Arrupe Booth 7. The poster was created to attract attention, communicate the event details, and encourage students to visit through the use of creative visuals, typography, and layout.

## 📚 What Have I Learned?

- I learned how to create an effective promotional design that communicates information clearly while attracting the audience's attention.
- I gained experience choosing fonts, colors, and visual elements that match the theme of an event.
- One challenge was arranging the text and design elements to make the poster visually appealing without making it overcrowded.
- I addressed this by organizing the information according to importance and using design elements that complemented the coffee theme.
- In the future, I can apply these skills in creating posters, advertisements, and other promotional materials.
